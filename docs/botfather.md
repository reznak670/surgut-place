## Команды

### Для всех (`/setcommands`, scope по умолчанию)

Вставить в BotFather одним сообщением:
```
start - Начать заново
menu - Главное меню
weekend - Вечера на выходные
filters - Найти по фильтрам
bookings - Мои брони
saved - Сохранённое
about - О проекте
help - Как пользоваться
```

### Для партнёров и админов

В BotFather команды задаются только для всех сразу. Видимость `/partner` и `/admin` для отдельных людей настраивает **frontend через API** при старте бота и при назначении роли:

```python
# админам — при старте, для каждого tg_id из ADMIN_IDS
await bot.set_my_commands(USER_COMMANDS + [BotCommand(command="admin", description="Админка")],
                          scope=BotCommandScopeChat(chat_id=admin_id))
# партнёру — сразу после назначения роли (и снять при снятии роли: delete_my_commands с тем же scope)
await bot.set_my_commands(USER_COMMANDS + [BotCommand(command="partner", description="Кабинет партнёра")],
                          scope=BotCommandScopeChat(chat_id=partner_tg_id))
```
Тексты описаний: `admin - Админка`, `partner - Кабинет партнёра`. Даже если кто-то наберёт команду вручную, хендлер всё равно проверяет роль (`error.no_access`).

## Пошагово: что куда вставить

1. Откройте [@BotFather](https://t.me/BotFather), отправьте `/mybots` и выберите бота.
2. **Edit Bot → Edit Name** — вставьте name.
3. **Edit Bot → Edit About** — вставьте about.
4. **Edit Bot → Edit Description** — вставьте description.
5. **Edit Bot → Edit Description Picture** — отправьте `assets/description.png` **как фото** (не файлом).
6. **Edit Bot → Edit Botpic** — отправьте `assets/avatar.png` как фото.
7. **Edit Bot → Edit Commands** (или `/setcommands`) — вставьте блок команд «для всех».
8. **Bot Settings → Group Privacy** — оставить включённым (Enabled): бот работает в личке и в админ-чате, читать всю группу ему незачем.
9. **Bot Settings → Inline Mode** — выключено. «Поделиться» сделано url-кнопкой, inline-режим не нужен.
10. Проверьте с телефона: откройте `t.me/<username>` в новом чате. Должны быть видны картинка, description и кнопка «Старт», а меню команд (кнопка `/`) — показывать 8 команд.

То же можно сделать без BotFather, через Bot API: `setMyName`, `setMyDescription`, `setMyShortDescription` (это about). Картинку описания и аватар через API поставить нельзя, только в BotFather.
